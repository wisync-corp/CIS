# CIS Frontend (fase inicial)

Interface React + TypeScript + Vite. **Sem autenticação, API ou dados de produção nesta etapa.** As páginas apresentam estados vazios deliberadamente.

Requisitos: Node 20+.

```sh
npm install
npm run dev
npm run build
```

Não colocar credenciais MySQL no frontend. Ligação futura exclusivamente através de API autenticada.
